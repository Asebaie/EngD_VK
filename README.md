# ДЗ 1. Эволюция систем обработки больших данных

Архитектура четырёх систем с разными профилями нагрузки: требования, схема, обоснование с отвергнутой альтернативой и главный компромисс.

| Кейс | Решение |
|---|---|
| 1. Ежедневный отчёт о продажах | Airflow, DuckDB на выделенном сервере, PostgreSQL, Superset |
| 2. Контроль выполнения доставок | Сервис приёма, Kafka, Flink, ClickHouse, Grafana |
| 3. Система бронирования билетов | PostgreSQL с двумя синхронными репликами, Patroni, etcd |
| 4. Обновление электронных ценников | Kafka, агент магазина на SQLite, правило «касса не дороже ценника» |
